Questions
Is it really 100% local?+
Yes. Your notes live in a SQLite file on your machine and the embedding model runs on-device. There are no accounts, no servers, and nothing is sent anywhere. The optional AI-agent plugin only talks to your own local CORTEX.
Do I need API keys or a subscription?+
No. Semantic search, auto-linking, and the Gardener all run for free on a local model — no OpenAI key, no monthly fee.
Can I bring my Obsidian vault?+
Yes — CORTEX imports a folder of Markdown losslessly, including [[wikilinks]], and can export back to Markdown whenever you want. No lock-in.
What does "works in any agent" mean?+
CORTEX ships a Model Context Protocol (MCP) server — a single zero-dependency file. Point Claude Desktop, Cursor, Cline, Continue, or any MCP client at it and your agent can capture to and recall from your brain.
What's the "Gardener"?+
A background agent that links related notes by meaning, sorts them into projects, and resurfaces stale ones. Linking is automatic; the judgement calls land in a review queue you control. It never rewrites your words.
